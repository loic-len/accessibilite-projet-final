# AtelierLocal — Projet final

Application React de démonstration pour le projet d’accessibilité. Commencez par `ENONCE.pdf` ou `ENONCE.md`. Le projet fourni contient des défauts intentionnels ; les tests de démarrage ne garantissent pas son accessibilité.

## Lancer

Node.js 24.15 ou plus récent dans la branche 24 est recommandé. Les branches 22 (à partir de 22.22.2) et 26 ou plus récentes sont également compatibles.

```sh
npm ci
npm run dev
```

## Vérifier

```sh
npm test -- --run
npm run build
```

## Rendu

- Membres du binôme : à compléter dans ce README.
- Copier MODELE-AUDIT.md en AUDIT.md puis le compléter.
- Créer et intégrer le composant « Poser une question à l’organisateur ».
- Aucun envoi réel. Utiliser uniquement des coordonnées fictives.

Le projet fonctionne sans polices, images ou services distants. Les illustrations SVG sont des créations propres à cet exercice. Les données sont fictives. `AIDES-TECHNIQUES.md` contient les références utiles.
